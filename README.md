# Mundo Pet Feliz

Landing page responsiva de vendas para o nicho pet.

## Estrutura

- `index.html` — página principal
- `assets/css/style.css` — estilos
- `assets/js/script.js` — carrinho e interações

## Recursos

- Hero promocional
- Categorias
- Produtos
- Carrinho lateral
- Cupom promocional
- Benefícios
- Depoimentos
- FAQ
- CTA final
- Botão de WhatsApp
- Layout responsivo

## Publicação

O projeto é estático e pode ser publicado em GitHub Pages, Netlify, Vercel ou qualquer hospedagem simples.

> Os produtos, preços, depoimentos e dados comerciais são demonstrativos e devem ser substituídos pelos dados reais da loja.
